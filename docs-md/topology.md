h.3 Хранение
Данные сохраняються только в аггрегированном состоянии для масштабов:
- пять секунд (ag5s), порт 37000
- одна минута (ag1m), порт 37001
- семь минут (ag7m), порт 37002
- один час (ag1h), порт 37003
- один день (ag1d), порт 37004 
Выбор масштабов исторический, можно сконфигурировать любой набор. Также исторически сохраняеться 3000 точек для каждого масштаба, но можно настроить на любое значение. Хранение осуществляеться в RocksDB с поддержкой TTL (устаревшие даные удаляються автоматически). Каждый масштаб можно сконфигурировать в отдельные демоны, раньше так и было, сейчас объеденены в один, но сконфигурированы так, чтобы можно было легко разъеденить и разнести по разным серверам. Данные для каждого масштаба храняться в отдельной дирректории, напиример /monamour/btp/ag5s/. Для каждого графика создаеться внутренний целочисленный индификатор, связь с именем храниться в базе keys/, а сами данные расшардены по шестнадцати базам  data/0/..data/15/. Все шестнадцать баз работают в одном окружении, настройки которого можно задать файле rocksdb-data.ini. Для базы ключей свое окружение rocksdb-keys.ini.
Для каждого масштаба также открыт отдельный порт для входящего потока данных, соответственно 36000..36004. 
```json
{
  "name":"",
```
```
  "ts": 0,
  "count": 0, // Общее количество
  "lossy": 0, // Количество не учтенных
  "min": 0,   // min - это не 0% с потярми
  "max": 0,   // Ахтунг! Если есть потери, то max-это не 100%
```
```
  "perc50": 0,
  "perc80": 0,
  "perc95": 0,
  "perc99": 0,
  "perc100": 0, // Условно. Максимальное на прореженных данных
```
```
  "data":[0]
} 
```
